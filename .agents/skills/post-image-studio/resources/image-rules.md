# Image Quality & Style Guidelines

- **Context-Driven Educational Visuals**: Images must NOT be generic stock photos or decoration. Each image prompt MUST be specifically tailored to visually explain, clarify, or diagram the core concept of the section it sits in (e.g. visualizing a 4-step consulting framework, comparing freelance vs. in-house workflows, displaying clean data analytics dashboards). The reader should feel: "Viewing this image helps me understand the section's core idea better!"
- **Aspect Ratio**: Default to 16:9 for article header and inline content images.
- **Aesthetic**: High-end editorial photography, modern minimalist setups, clean diagrams, warm natural lighting, professional environment.
- **Text & Logos**: Absolutely NO baked-in text, typography, brand trademarks, or copyrighted logos inside generated images.
- **Human-Written SEO Alt Text**: Alt text must naturally incorporate target and secondary LSI keywords while accurately describing the visual subject as if written by a human SEO editor. Never use generic alt text like "image 1".
- **Pre-Draft Audit Gate**: Every package MUST undergo AI content verification, word count audit, and image metadata check BEFORE drafting on WordPress.
