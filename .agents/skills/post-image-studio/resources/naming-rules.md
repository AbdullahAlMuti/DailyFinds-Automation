# Naming Conventions for Images

- **Format**: All filenames must be lowercase, hyphenated, and alphanumeric only (`a-z`, `0-9`, `-`).
- **Pattern**: `<slug>-<placement>-<width>x<height>.<ext>`
- **Examples**:
  - `best-ai-side-hustles-featured-1600x900.webp`
  - `best-ai-side-hustles-featured-1200x630.jpg`
  - `best-ai-side-hustles-inline-1-1200x675.webp`
